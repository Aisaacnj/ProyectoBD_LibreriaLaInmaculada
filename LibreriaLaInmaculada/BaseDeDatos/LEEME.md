# Base de datos

Ejecutar en SQL Server Management Studio, completos (F5), en este orden:

1. `LibreriaLaInmaculada_v7.sql`: crea la base `LibreriaLaInmaculada` con sus 10 tablas, índices, vistas y triggers. Si ya existía, la deja vacía.
2. `LibreriaLaInmaculada_v7_datos.sql`: la llena con el año escolar 2026 simulado (2 usuarios, 8 proveedores, 50 artículos, compras, ventas y pérdidas). Solo funciona con la base vacía.

Para volver a empezar desde cero, ejecute los dos otra vez en el mismo orden.

Estos archivos no forman parte del programa: se guardan aquí para que todo el equipo tenga la misma versión.
